# Discernment

A Working product and a good product is not always the Same.
Differentiate a good product from working one.

> Five Lenses that help
>
> - Functional Integrity, Does it actually work, technical code review, consider all test cases to ensure functional integrity, TDD
> - Production readiness, Does it Work under load, Geneerate production scenaries, ask "What production assumptions does the code make"
> - Problem fit, Does it solve the user Actual problem?
> - Experience qulaity, is it actually good, is the experience clear intuitive, accessible, Ai doesnt have taste.
> - Responsible impact, is it repsonile, bias, privacy, unintended consequences, make sure code doesnt propagate harmful assumptions

> Ai needs your oversight to produce a product that matters

## Discernment for user experience

1. Clarity (simplificity)
2. Hierarchy and prograessive Disclosure
3. Accessibility as a baseline
4. Feedback and responsiveness

> Description and Discernment going hand in hand
> A bad description is "make it look good"
> A good description is "use Material ui use 1 color to indicate this, make it hiearical, dont overwhelm the user, Simpliciity first"
> You describe the Experience!
